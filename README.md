# Footprint-Aware Planning for Robotic Drawing and Physical Inpainting

Review resources for the manuscript. Open `index.html` for the project overview, physical examples, method diagram, and benchmark results. The manuscript is in `assets/paper.pdf`.

The figures summarize 416 drawing images, 140 evaluated image-edit examples, five tool diameters (1–5 mm), and 70 executed physical actions. Digital footprint scores are separate from physical demonstrations.
